# Mein Nachrichten-Überblick (Handy-Version)

Dateien in diesem Paket (alle liegen im Hauptordner des Repositorys):
- index.html – die Webseite
- update.py – holt die Meldungen und berechnet die Top 10
- sources.json – Ihre Quellenliste (hier ändern Sie Portale)
- items.json, data.json – Datenspeicher, werden automatisch gefüllt
- workflow-inhalt.txt – Inhalt für die Zeitplan-Datei (wird von Hand angelegt, siehe Chat)

Die Seite aktualisiert sich alle 3 Stunden. Kosten: 0 €.
Quellen ändern: sources.json im Repository öffnen, Stift-Symbol, bearbeiten, speichern.
